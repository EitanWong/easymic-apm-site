# 认识 EasyMic APM

EasyMic APM 是声音的**前端声学处理层**。麦克风采集的声音经过处理后，再交给应用进行通话、录音、传输或语音输入。它同时提供原生处理库和接入 EasyMic 工作流的 Unity Package。

## 三项基础能力

| 能力 | 解决什么问题 | 常见场景 |
| --- | --- | --- |
| AEC · 声学回声消除 | 减少扬声器播放声音被麦克风再次采集 | 免提通话、数字人交互、边听边说 |
| ANS · 噪声抑制 | 减轻风扇、空调与环境背景噪声 | 办公室、展陈终端、语音采集 |
| AGC · 自动增益控制 | 缓解声音随说话音量与距离忽大忽小 | 语音聊天、录音与语音输入 |

这些能力由软件算法提供。接入基础 AEC、ANS、AGC 不要求昂贵或复杂的阵列麦克风；普通麦克风也可使用。麦克风质量、摆放、设备音频路由与房间声学仍会影响最终效果。

## 可以用在哪里

- **展陈与数字多媒体**：博物馆、数字人一体机、现场互动终端。
- **桌面 AI 与语音交互**：桌面精灵、语音指令、应用语音输入。
- **游戏与交流**：游戏语音、虚拟空间、语音聊天与远程协作。
- **采集前端**：将更清晰、音量更稳定的声音交给后续存储、编码或语音服务。

## 原生库与 Unity Package

原生库提供统一 C 接口，适合接入原生应用、.NET 或其他 FFI 宿主的音频链路。详见[原生库接入](native.md)。

Unity Package 为 `com.eitan.easymic.apm`，依赖先安装的 `com.eitan.easymic` 基础采集包，再把 APM 处理接入 EasyMic 工作流。详见[Unity 快速接入](unity.md)。

## 使用条件

AEC 需要应用提供与实际扬声器输出匹配的播放参考。它不应被理解为“只打开开关就能消除任意来源的声音”。详见[设备与声音配置](audio-setup.md)。

基础降噪不是同方向说话人的身份分离。实际效果需要在目标设备与环境中验证。

[定向拾音](directional.md)是独立的实验性扩展，需要同步的物理阵列输入、实测几何以及相应授权。短双麦阵列和复杂房间仍有明显限制。
