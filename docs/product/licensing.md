# 授权与购买

Unity 插件有单机版和专业版两种形式。两者的主要差别是**授权绑定的位置**。以下为人民币价格。

## 单机版 · ¥{{devicePrice}}

单机版绑定**目标部署机器**，即 Unity 打包后的应用最终运行的那台设备。只有绑定的目标机器可以使用被授权的 EasyMic APM 前端声学功能。

适合展陈、博物馆和数字多媒体行业的 To B 交付，如数字人一体机、展陈终端、现场单机项目。优势是授权价格较低，适合固定设备部署。

```text
Unity 构建 → 绑定的目标终端 → 使用 APM 声学功能
                 ↑
             授权绑定在这里
```

购买时请向作者说明目标终端与部署计划，并按交付要求提供授权信息。更换目标机器等授权安排请联系作者。

## 专业版 · ¥{{professionalPrice}}

专业版绑定**开发机**。由该开发机构建出的任何应用程序，都可以使用 EasyMic APM 的前端声学功能，不需要将每台用户运行设备逐一绑定。

适合个人开发者、To C 工作室、桌面 AI 精灵、游戏语音项目，以及面向 Steam 等渠道分发的应用。

```text
绑定的开发机 → 构建应用 → 分发到用户设备使用
     ↑
 授权绑定在这里
```

| --- | --- | --- |

## 原生库与源代码

需要原生 SDK、源代码或其他集成授权的开发者，可以单独联系作者沟通授权与报价。这类授权独立于本页所列 Unity 插件价格。

## 在 Unity 中完成授权

在 **Project Settings → Easy Mic → APM 授权** 中查看并按作者要求提供授权标识。单机部署还需按交付流程提供目标运行机器信息。获得授权后，导入授权内容并确认所需能力可用，再验证实际构建产物。详见[Unity 快速接入](unity.md)。
